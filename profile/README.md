## 在做什么

从数据、tokenizer 到架构和优化器，每个设计都先做对照实验再决定。目前预训练已经完成，正在做中训练，之后是 SFT、RL、多模态和 agent。每个实验的结论、花费和训练曲线都在[公开构建](https://cookllm.com/lab)页，课程内容在[课程文档](https://cookllm.com/docs)。

## 代码仓库

三个仓库是课程会员专属的私有仓库：

| 仓库 | 内容 |
